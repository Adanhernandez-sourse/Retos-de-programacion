# Reto 15 - Lectura del archivo con la imagen del ahorcado

Lee un archivo ahorcado.txt que contiene las figuras del juego del ahorcado.
1. Define estructura Etapa con arreglo de lineas.
2. Abre el archivo con ifstream y lee linea por linea con getline.
3. Guarda cada figura en un arreglo de estructuras, separadas por ===.
4. Muestra las figuras en forma secuencial, esperando ENTER entre cada una.
