# Reto 14 - Uso de arreglos de estructuras

Muestra como usar arreglos de estructuras con apuntadores en C:
1. Crear arreglo de estructuras Alumno con 3 alumnos.
2. Recorrerlo con grupo[i].campo.
3. Recorrerlo con apuntador (p + i)->campo.
4. Modificar un campo con apuntador p->campo.
5. Recorrerlo con otra forma p[i].campo.
